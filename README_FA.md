# راه‌اندازی SSB با Node.js در ویندوز

## نصب و اجرا
1. نسخه LTS از https://nodejs.org را نصب کن (Node.js 20 یا بالاتر).
2. ZIP را استخراج کن و در پوشه `SSB_NodeJS` از نوار آدرس File Explorer عبارت `cmd` را وارد کن.
3. دستورات زیر را جداگانه اجرا کن:

```cmd
node --version
npm install
npm start
```

سپس http://localhost:3000 را باز کن.

## حساب مدیریت پیش‌فرض
- نام کاربری: `admin`
- رمز عبور: `ChangeMe-123!`

## امکانات افزوده‌شده در این نسخه
- ضبط و ارسال پیام صوتی از میکروفون مرورگر
- تماس صوتی و تصویری یک‌به‌یک با نام کاربری طرف مقابل، با WebRTC و سیگنالینگ Socket.IO
- عکس پروفایل کاربر
- انتخاب عکس هنگام ساخت گروه یا کانال
- پنل مدیر شامل فهرست همه پیام‌ها و پیوند فایل/صداهای پیوست‌شده و امکان حذف پیام

## نکته‌های مهم
- برای تماس، هر دو نفر باید هم‌زمان آنلاین و وارد حساب باشند. دوربین/میکروفون را در مرورگر تأیید کنید. تماس در `localhost` قابل آزمایش است؛ برای استفاده از دستگاه‌های دیگر یا اینترنت معمولاً HTTPS لازم است. سرور STUN عمومی تنظیم شده؛ برای شبکه‌های محدود ممکن است به TURN نیاز باشد.
- تماس فعلی یک‌به‌یک است و هنوز تماس گروهی یا اعلان زنگ کامل ندارد.
- مدیر می‌تواند متن پیام‌ها و فایل‌های پیوست‌شده را در پنل مدیریت مشاهده کند؛ این موضوع باید به کاربران اطلاع داده شود. این نمونه رمزنگاری سرتاسری ندارد.
- داده‌ها در `data.json` و فایل‌ها در `uploads` ذخیره می‌شوند. این پروژه نمونه اولیه است؛ پیش از انتشار عمومی، مجوزها، CSRF، محدودیت درخواست، بررسی نوع واقعی فایل، پشتیبان‌گیری و تنظیمات نشست را تقویت کنید و رمز/secret پیش‌فرض را عوض کنید.
